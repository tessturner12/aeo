# AEO

## Structure

- `log.md` — daily journal, one entry per day
- `docs/plan.md` — 30-day plan
- `docs/code-appendix.md` — code appendix
- `research/` — Day 1–2 research notes and question extraction
  - `day1-category-check.md` — Day 1 manual test notes
  - `questions-raw.md` — Day 2 step 1, brain dump
  - `questions-expanded.md` — Day 2 step 2, expanded phrasings before clustering
  - `questions.csv` — Day 2 final structured output
- `src/` — Day 3 onward, the rig itself
  - `rig.py`
  - `parser.py`
  - `schema.sql`
- `.env` — gitignored, never committed
